# Roadmap

Planned work after launch. Each item is one pull request (or a few), discussed with Martin first.

- **New papers:** a weekly Semantic Scholar/ORCID job that proposes new papers as a pull request,
  with the themes left empty for the authors to fill in.
- **Paper thumbnails:** extracted for new papers in that pull request (the first figure of the arXiv
  source, else figure detection in the PDF, else a pattern seeded from the title).
- **Slides and talks:** where the lab publishes slides (GitHub releases or separate repositories) is
  still to be decided. The "Lecture slides" box on the Teaching page and the "Talks & media" tab
  appear once there is content.
- **German versions** of the main pages, if decided.
